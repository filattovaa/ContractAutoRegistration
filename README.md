# ContractAutoRegistration
# Автоматическая регистрация договоров в 1С

Внешняя обработка для пакетной регистрации договоров на основании данных из Excel-файла.

# Функциональность

- Загрузка списка договоров из файла `.xlsx`.
- Проверка дат начала и окончания действия договоров.
- Поиск документов, находящихся на этапе регистрации.
- Поиск связанных задач бизнес-процесса.
- Обновление реквизитов договоров.
- Выполнение задач и регистрация документов.
- Запись ошибок в журнал регистрации.

# Техническая реализация

- Управляемая форма, разделение клиентской и серверной логики.
- Передача файла через временное хранилище.
- Пакетный запрос с использованием временной таблицы.
- Сопоставление данных Excel с документами через `Соответствие`.
- Транзакционная обработка каждого договора.

# Особенности

Обработка разработана для конфигурации 1С:Документооборот с дополнительными объектами и механизмами. Для запуска в другой информационной базе потребуется адаптация к её метаданным. Для загрузки данных используется файл формата .xlsx с фиксированной структурой столбцов.

# Исходный код

`FormModule.bsl` — модуль управляемой формы внешней обработки.
